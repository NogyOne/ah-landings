# Halisco Landing Documentation

This directory records verified Halisco implementation facts and accepted product and visual intent. Use it to understand what is currently shipped, what guides future work, and where workspace-wide conventions live.

## Start here

- [Architecture](architecture.md) describes the current runtime, source boundaries, rendering mode, and implementation discipline.
- [Design brief](design-brief.md) captures accepted product, content, and visual intent for future implementation.
- [Workspace documentation](../../../docs/README.md) covers shared topology and repository-wide conventions.

## Documentation boundaries

Architecture is implementation truth backed by current source and configuration evidence. The design brief is accepted intent, not proof that a feature is present. Keep Halisco-specific behavior in this directory and link to the canonical workspace owner for cross-project guidance.

## Workspace context

The [workspace documentation index](../../../docs/README.md) is the entry point for shared architecture, skill conventions, and repository-wide documentation policy.
